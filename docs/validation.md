## 상황 설명 입력 검증

## 아직 검증하지 않은 항목

Multilingual OCR, 선택 번역 모델 및 식약처 인증 API의 실제 end-to-end 호출은 실행하지 않았다. 해당 어댑터의 요청/응답은 공식 문서와 테스트 대역으로 검증했다. 현재 제품 참고 자료는 조플루자·타미플루만 포함하며, 다른 약품을 자동으로 식별하는 범용 데이터베이스가 아니다.

OpenShell은 정책 예제와 배포 경계 문서만 제공하며 sandbox 배포를 실행하지 않았다. NemoClaw는 제외했다. 일반 build.nvidia.com Skill API를 임의 생성하지 않았다. ISO32000 전체 인증이나 모든 약관의 관련 조항 검색 완전성을 주장하지 않는다.

## 조플루자 누락 수정 검증

- 상표명만 있는 설명에서 제조사 제품자료의 성분 및 활성 대사물 근거를 검증해 발록사비르 검색에 연결한다. 인플루엔자 표현은 제품 관련 검색어이며 환자 진단으로 저장하지 않는다. 출처·자료 버전·확인일을 별도 카드에 표시한다.
- 사용자 제공412쪽 약관에서 사진 없이 “조플루자를 처방받았습니다.”로 로컬 실행: PDF237쪽 지급사유·정의와238쪽 발록사비르·신규 허가/허가 취소 안내를 포함한 원문29건 반환. 원본 파일·추출문·사용자 스크린샷은 배포물에 포함하지 않는다.
- 합성3쪽 PDF로 성분 → 관련 조항 → 변경 안내 연결, 대화용 표현으로 인한 무관한 페이지 제외, 원문 주석 저장 검증. 변조된 제품 근거와 출처 없는 약품명을 거절한다.
- 별도 임시 저장소/임의 포트의 Chromium에서 상표명만 있는 설명 → 제품 근거 카드/공식 링크 → 약관 원문/하이라이트 → 설명 지우기 → 기존 질의 검색 통과. OCR 요청0, 브라우저 오류0.
- 실제 NIM에서 기존 nvidia/nemotron-3-nano-30b-a3b는410, nvidia/nemotron-nano-3-30b-a3b는404가 반환되었다. 현재 기본값 nvidia/nemotron-3.5-lightning-30b-a3b는 인증된 JSON 및 native tool-call 단독 호출에 성공했다. 키 값은 기록하지 않았다.
- JSON mode 적용 전 전체 cloud workflow에서는 NIM_TIMEOUT과 잘못된 JSON을 관측했다. JSON mode와 엄격한 파싱을 추가했으며, 제공자 오류 시 로컬 근거로 복구하되 warnings 및 local mode를 표시한다. 출처 검증 오류와 취소는 복구 우회하지 않는다.

- JSON mode 적용 후 모델의 지원하지 않는 도구/동일 검색 반복도 관측했다. 허용 도구를 늘려 임의 실행하는 대신 `finish_retrieval` 빈 인자 완료 도구를 추가했다. 실패한 모델 지시는 실행하지 않으며, 명시적 로컬 재조사는 원문 검증을 다시 거친다.
- 최종 실제 NVIDIA + native NAT 전체 실행: 공개 약품명과 합성 약관만 사용해28.116초, mode=nim-react, warnings=[], 성분이 포함된 원문4건 및 제품 근거1건 반환 성공. 이는 단일 성공 관측이며 서비스 지연/모델 오류가 항상 없다는 보장이 아니다. 사용자 의료자료는 이 cloud 검증에 보내지 않았다.
- API 키가 설정된 환경의 시간 초과를 테스트 대역으로 발생시킨 격리 브라우저 검증: NVIDIA 전송 동의 후 로컬 복구 안내, 공식 근거, 원문 하이라이트 표시 성공.

## 새로고침 시 이전 결과 복원 수정

완료된 조사 결과를 자동 복원하던 UI 코드를 제거했다. 새로고침 시 약관만 복원하고, 진행 중인 작업은 SSE 재연결을 유지한다. 검색 결과 지우기는 현재 대화·결과·하이라이트·다운로드 선택을 초기화하며 입력 내용, 원본 PDF와 서버 기록은 보존한다.

격리된 임시 서버/합성 PDF의 Chromium 검사에서 결과 지우기, 설명·약관 보존, 완료 결과의 새로고침 후 미복원, 진행 중 작업 재연결, 이후 재검색과 하이라이트를 확인했다. 브라우저 오류0. 현재8000번 서버에서도 수정된 정적 파일 제공을 확인했다. 이전 검증 목록의 완료 결과 자동 복원 동작은 이 변경으로 대체된다.
